AI UGC Images

Four AI-generated characters, each kept visually consistent across nine images.

Role

AI Image & Character Designer

Scope

AI Image Generation · Character Consistency · Photo Editing

Tools

(01) — The project

The Project

This project is about keeping a character looking like themselves across a full set of images. I generated a base identity for each character in Higgsfield Soul 2.0, then used ChatGPT and Google Flow together to write, refine, and generate each new image.
